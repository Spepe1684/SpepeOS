# SpepeOS
My own custom webpage in the form of an OS that contains multiple draggable windows featuring information about me, especially my love of the character Toro the cat. Made as part of my project for Hack Club's StarDance Challenge.


![SpepeOS screenshot](<Screenshot 2026-10-28 182636.png>)

It features Toro Inoue the cat a lot!
Other features:
 - A welcome screen, showing the name of the OS as well as Toro's first feature. You can close it and open it again by clicking the top bar.
 - A notes app, where the user can see notes I have made as well as edit and write their own new notes.
 - A photo gallery showing Toro doing random things in everyday life.
 - Web icons to click to open the notes and photo gallery app.
 - Live time on the top bar.

To try this out, click the link and it should open my OS: https://spepe1684.github.io/SpepeOS/

As of 10/09/2026, I currently have a notes app where you can see some of my notes as well as add your own, as well as a photo gallery featuring a couple images of Toro doing random stuff!
All the photos are from pinterest.
I relied a lot on the tutorial graciously given by hack club to make the foundations of my webOS, as well as many youtube videos to learn how to make certain features (such as my notes app, where the user can directly edit the notes).
